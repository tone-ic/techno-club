# ADR 003 — Tap-to-move как основной режим управления на мобайле

**Статус**: Принято  
**Дата**: v2.0

## Контекст

Нужно управление персонажем на iPhone без физической клавиатуры.

## Решение

**Tap-to-move** — основной режим. Виртуальный джойстик (nipple.js) — опциональный.

## Обоснование

DOOR//CLUB — социальный симулятор, не шутер и не платформер.
Точное управление важно, но не критично каждую секунду.
Пользователи привыкли к tap-to-move из мобильных RPG (Diablo Immortal, Path of Exile Mobile).

Tap-to-move реализуется через:
1. Raycast из точки тапа на navmesh
2. A* pathfinding к целевой точке
3. Персонаж идёт по пути с анимацией walk

Джойстик остаётся для:
- Тонкого маневрирования в толпе
- Пользователей, предпочитающих его

## Последствия

- Нужен navmesh для обеих сцен (outside, club)
- Нужна реализация A* или использование PlayCanvas навигационного плагина
- Тап на другом игроке — контекстное меню (разговор, репорт), не движение
- Тап на объекте (бар, DJ booth) — приближение к нему
