# ADR 002 — Fly.io вместо Render Free для Colyseus

**Статус**: Принято  
**Дата**: v2.0

## Контекст

Нужен хостинг для Colyseus game server. Должен быть бесплатным на этапе теста и не засыпать.

## Решение

Использовать **Fly.io free tier** для Colyseus и Hono API.

## Обоснование

Render Free засыпает через 15 минут без запросов. Cold start занимает 30+ секунд. Для WebSocket-сервера это критично: игроки получат таймаут при попытке подключиться.

Fly.io free tier:
- 3 shared-CPU машины, 256 MB RAM каждая
- **Не засыпает**
- WebSocket keepalive работает нативно
- Docker-based деплой
- Глобальные регионы (выбрать `fra` для Европы)

## Последствия

- Каждое приложение (`game-server`, `api`) — отдельное Fly app
- `fly.toml` в каждом из приложений
- Деплой: `fly deploy` из директории приложения
- Логи: `fly logs`
- Мониторинг: `fly status`
