## Конфиденциальность

- Оригинальные фото (лицо, тело) **никогда** не показываются другим пользователям.
- Оригинальные фото удаляются с сервера через ≤ 5 минут после генерации аватара.
- EXIF-данные фото (геолокация, устройство) удаляются на клиенте до отправки.
- Фейсконтроль видит **только виртуальный аватар** — без реального лица, тела, email, имени.
- `face_texture_url` скрыт от других пользователей через Supabase RLS.
- TRELLIS/любой image-to-3D worker получает только уже сжатые, EXIF-free изображения и не хранит их после завершения job.
- TRELLIS-модель должна проходить стилизацию/LOD перед показом другим пользователям: цель — клубный аватар, не фотореалистичная копия человека.

## Возраст

- Приложение **18+**.
- При регистрации обязательное подтверждение возраста.
- Контент (звук, образы, общение) — для взрослых.

## Фейсконтроль

- Отказ возможен только с **reason code** из списка: `dress_code`, `overcrowded`, `behavior`, `closed_event`, `vibe_check`.
- `vibe_check` — лимит 1 раз в 30 минут на одного игрока от одного фейсконтроля.
- После 3 отказов подряд от одного фейсконтроля → **автоматическая эскалация** администратору.
- Роль фейсконтроля — только по выдаче администратора, с TTL.
- Все действия фейсконтроля **логируются** (timestamp, bouncer_id, guest_id, reason).
- Игрок всегда может подать **жалобу** на фейсконтроля.

## Модерация

- Все moderation actions пишутся в `moderation_actions` с временной меткой.
- Бан выдаётся с указанием причины и срока.
- Мут — временный, с указанием причины.
- Кик из комнаты не является баном.

## Музыка

- DJ транслирует только музыку, на которую имеет права.
- Платформа показывает предупреждение на DJ-странице.
- Для тестов — только royalty-free или собственная музыка.

## Технические правила

- `service_role` ключ Supabase — никогда в клиентский код.
- Все игровые решения (очередь, вход, кик) принимает сервер, не клиент.
- Аватар — стилизованный, не фотореалистичный, чтобы снизить риски дискриминации.
